# المزرعة الذكية (Smart Farm)

منصة متابعة وتحكم في مزرعة ذكية: متحكم **ESP8266** بحساسات (رياح، رطوبة تربة، مستوى ماء) ومضخة عبر ريلاي، وخادم **Python** بقاعدة بيانات وجدولة سقي وتوصيات زراعية، وواجهة ويب عربية، وخدمة **ذكاء اصطناعي معزولة** لجمع بيانات التدريب.

## المكونات

| المجلد | المحتوى |
|---|---|
| `firmware/farm_sensors` | برنامج الـ ESP8266 (قراءة الحساسات، المضخة، واجهة HTTP، إعداد الواي فاي) |
| `firmware/farm_pump`, `wind_test`, `soil_test` | نسخ واختبارات سابقة لكل حساس |
| `platform/server.py` | خادم المنصة (API، قاعدة بيانات SQLite، جدولة السقي، التوصيات) |
| `platform/static` | واجهة الويب (HTML/CSS/JS، خط Cairo محلي، أيقونات SVG) |
| `platform/ai` | خدمة الذكاء الاصطناعي المعزولة (`ai_service.py`) والنموذج (`model.py`) |
| `start_farm.bat` | تشغيل المنصة وخدمة الذكاء معاً |

## التشغيل

1. **برنامج اللوحة:** انسخ `firmware/farm_sensors/secrets.example.h` إلى `secrets.h` واملأ اسم الشبكة وكلمة المرور ومفتاحاً سرياً، ثم ارفع `farm_sensors.ino` (لوحة *NodeMCU 1.0 ESP-12E*، حزمة `esp8266`).
2. **المنصة:** `python platform/server.py http://smartfarm.local 8000` ثم افتح `http://localhost:8000`.
   أول تشغيل ينشئ `platform/config.json` برمز دخول (PIN) يُطبع في الشاشة ويقرأ المفتاح من `secrets.h`.
3. **الذكاء الاصطناعي (اختياري):** `python platform/ai/ai_service.py` (منفذ 8100، قاعدة بيانات وتوكن خاصان). إيقافه لا يؤثر على المنصة.

لا مكتبات خارجية للخادم سوى `pyserial` لأدوات USB القديمة (`farm_monitor.py`).

## التوصيل (ESP8266)

| الحساس | التوصيل |
|---|---|
| الرياح (نبضي) | IO14 + GND |
| رطوبة التربة | A → ADC، VCC → 3V3، D → IO12 |
| مستوى الماء | S → IO4، + → IO13، − → GND |
| ريلاي المضخة | IN → IO5 |

## ما لا يُرفع إلى المستودع

`secrets.h` و`platform/config.json` (أسرار)، وقواعد البيانات `*.db` و`platform/ai/data/`، ومجلد `tools/` (أدوات تُنزَّل تلقائياً).

## الحمايات

الحمايات الحرجة مبرمجة في اللوحة نفسها: لا تشغيل بخزان فارغ (إلا يدوياً)، وحد زمن لكل تشغيل، ومضخة مطفأة عند الإقلاع، وأوامر المضخة بمفتاح سري.
